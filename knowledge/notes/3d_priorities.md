# 3D-моделирование DOLG — приоритеты по скорости и важности

Прикладная приоритизация ~30 задач из [3d_roadmap.md](3d_roadmap.md) по матрице «скорость × импакт». Каждый tier — независимый временной горизонт.

Размеры: **XS** = часы, **S** = 1–2 дня, **M** = 3–7 дней, **L** = ~2 недели, **XL** = ~месяц.

---

## 🟢 Tier 0 — Quick wins (~2–3 недели суммарно)

Высокий импакт, малая стоимость. Делать **первыми**, многое можно параллельно.

| № | Задача | Скорость | Импакт | Зачем именно сейчас |
|---|---|---|---|---|
| 1.5 | OrbitControls polish (damping, zoomSpeed, rotateSpeed) | XS | средний | Почти бесплатно, сразу «professional feel» |
| 1.3 | GLB-экспорт через `THREE.GLTFExporter({binary:true})` | S | **высокий** | Открывает AR-предпросмотр и sharing PCB одной строкой кода |
| F5 | AR-предпросмотр через `<model-viewer>` (после 1.3) | S | **wow** | QR-код на слайде защиты → плата на телефоне в AR |
| 1.1 | Расщепить scheme-3d.js на модули | M | **критично** | Блокер для всего Tier 1, без него фичи смешаются |
| 1.6 | 3D thumbnail в HTML/PDF review | M | **высокий** | Закрывает backlog-пункт из плана typed-mixing-hammock |
| 2.7 | Cross-probing 2D↔3D (клик в схеме → подсветка в 3D) | M | **высокий** | Связь модулей DOLG, реальная инженерная фича |
| 4.4 | Thermal map overlay (связь с Pro analytics) | M | **критично** | Использует уже сделанный simulation_analysis.py, даёт сильный демо-кадр |

**Итого Tier 0:** ~2–3 недели чистого времени; закроет два backlog-пункта (thumbnail, cross-probing) и добавит AR + thermal map для защиты.

---

## 🟡 Tier 1 — Стратегический пакет (~6–8 недель)

Базовый 3D-редактор плюс реалистичные модели. Это и есть «полноценное проектирование».

### Реалистичность (Фаза 2)

- **2.4** Top/bottom toggle — S
- **2.3** Multi-layer stack-up — M
- **2.6** Explode view (layer animation) — S, killer-кадр для диплома
- **2.1** Library реальных STEP-моделей (топ-20 footprint'ов) — L, главный визуальный апгрейд
- **2.2** `GLTFLoader` с fallback на процедурную модель — S, зависит от 2.1

### Базовый редактор (Фаза 3)

- **3.6** Модель `PCBLayout` в БД — M, **фундамент**, делать первым в этом блоке
- **3.1** Click-select + outline — S
- **3.2** Drag-drop размещение — M
- **3.3** Inspector panel — M
- **3.5** Undo/Redo стек 3D — M
- **3.8** Импорт BOM из schematic как «to be placed» — M, **критичная связка** «нарисовал схему → расставил в 3D»
- **3.7** Footprint-палитра из каталога DOLG — M, мост каталог→3D
- **1.2** `InstancedMesh` — S, нужен когда плат >50 компонентов

**Итого Tier 1:** ~6–8 недель чистой работы, даёт защитопригодную фичу «редактор PCB с реальными корпусами и слоями».

## 🔴 Tier 3 — Опциональный бэклог (после защиты)

- **Stress-map при изгибе платы** — L, нишевая mechanical-фича

---

## Рекомендация: первые 3 шага

1. **Начать с 1.1 (расщепить scheme-3d.js)** — это блокер, после него остальное идёт быстрее.
2. **Сразу за ним 1.3 + AR-предпросмотр + 4.4 thermal map** — три фичи, которые сразу видны на защите за минимум усилий.
3. **Затем Tier 1 целиком**, начиная с 3.6 (`PCBLayout` модель) — без БД нет редактора.

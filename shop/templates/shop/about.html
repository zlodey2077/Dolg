Зачем

Идея: вместо того чтобы инженеру держать в голове три отдельных приложения — каталог поставщика, симулятор и CAD, — сделать одну точку входа. Открыл страницу, нарисовал схему, прогнал ngspice, скачал BOM-список, сразу добавил все компоненты в корзину магазина. На защите дипломного проекта это демонстрирует полный цикл «идея → симуляция → закупка».

Возможности

Полный цикл «схема → BOM → корзина»
Открыть демо-схему «🎚 Двухкаскадный усилитель класса А» → запустить DC-анализ → нажать «📋 BOM» → выбрать альтернативы → «🛒 Добавить всё в корзину» → оформить заказ. ~2 минуты.
АЧХ/ФЧХ фильтра
Открыть демо «📊 Двухкаскадный RC-фильтр» → переключить тип анализа на «АЧХ/ФЧХ (AC)» → запустить → увидеть спад −40 дБ/дек.
Стресс-тест ngspice
Открыть «🪜 Лестница R-2R ×100» (≈600 элементов) → запустить DC → ngspice.wasm решает за миллисекунды.
Сравнение товаров с авто-аналитикой
Из каталога добавить 3 товара в сравнение → таблица с авто-определением «лучше/хуже» по типу параметра, чемпион по числу побед — золотой плашкой.

Технологический стек

  • Backend: Django 6.0, Python 3.14
  • База данных: SQLite (dev), PostgreSQL-готов
  • Frontend: ванильный JS + Canvas 2D
  • Симулятор: ngspice 33 в WebAssembly
  • JS-fallback: собственный MNA-солвер (Гаусс)
  • PDF: reportlab (гарантия, сертификат)
  • Worker: Web Worker для ngspice + MNA
  • Public access: Cloudflare Tunnel
  • Стандарты: ГОСТ 2.728, 2.730, 2.104
  • Тесты: pytest-django + coverage ({{ stats.tests }}+ тестов)

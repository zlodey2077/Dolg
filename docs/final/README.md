# Финальная сборка DOLG

Эта папка предназначена для материалов, которые идут в итоговую сдачу и демонстрацию:

- дипломная записка;
- презентация;
- речь и ответы на вопросы;
- актуальные скриншоты;
- релизный архив;
- A3-изображения крупных схем и диаграмм.

Перед упаковкой проекта запустите:

```powershell
.venv\Scripts\python.exe manage.py check_demo_ready
```

Для запуска сайта без VS Code используйте `start_local.bat` (локально) или `start_public.bat` (с публичной ссылкой через Cloudflare Tunnel) из корня проекта.

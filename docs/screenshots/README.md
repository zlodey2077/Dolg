# docs/screenshots

Каталоги для скриншотов, используемых в дипломе и приложениях:

- `catalog/` — главная, категории, карточка товара, корзина, сравнение
- `editor/` — симулятор, редактор схем, симуляции, AI-ассистент, 3D PCB, виртуальная лаборатория
- `cad/` — 2D-САПР, ГОСТ-рамки, блоки
- `knowledge/` — энциклопедия, лаборатория, обучение
- `chat/` — публичный чат, топики, сайдбар объявлений
- `org/` — Enterprise: dashboard, members, audit, conversations, settings
- `billing/` — Pro/Enterprise тарифы, квоты, активация trial
- `admin/` — Django admin, моделирование
- `metrics/` — терминал pytest/coverage/ruff

Полный список именованных PNG-файлов и тем — в [../SCREENSHOT_GUIDE.md](../SCREENSHOT_GUIDE.md).

**Внимание**: PNG-файлы НЕ должны попадать в git — добавьте `*.png` в .gitignore
этой папки, если используете публичный репозиторий. Для диплома хранить локально.

### 8. ✅ ngspice WASM warning в консоли при каждой симуляции

**Запрошено:** 2026-05-30 (скрин с error).
**Корень:** ngspice.wasm build не содержит BJT-моделей. На схеме с Q1/Q2 stdout пуст → парсер ругается → fallback на JS-MNA (корректно).
**Сделано:** снизил severity `console.warn` → `console.info`, убрал `showNotification('⚠')`. Сырой stdout доступен в `console.debug`.
**Файлы:** `simulation.html:8474-8482`.
**Подробно:** `docs/SCHEMATIC_EDITOR_FIXES.md#3`.

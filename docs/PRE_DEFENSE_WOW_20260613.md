## 🥇 Топ — высокий вау, низкий риск, успеваем (рекомендую этот порядок)

1. **RF-анализ: фронт + график S21/S11** — `S`, риск низкий, **вау высокий**
   Бэкенд (`rf_analysis.py`, `api_rf_analysis`) уже считает АЧХ фильтров. Не хватает только кнопки
   и графика (Plotly/Canvas). Закрывает готовый движок «в ноль» → на защите показываешь частотную
   характеристику фильтра вживую. Изолировано, ядро не трогает.

2. **Интерактивные probes (живые измерения по клику)** — `M`, риск средний, **вау высокий**
   Сейчас таб Probes = заглушка. Сделать: клик по проводу/узлу → прилипает пробник с live-значением
   (напряжение узла / ток ветви из MNA), подсветка перегруза. Закрывает placeholder + типичный вопрос
   комиссии «а измерить можно?». Добавочная фича поверх готового MNA.

3. **Генератор корпуса + экспорт STEP/STL** — `M`, риск низкий, **вау высокий** (мегацикл, этап 1)
   В 3D-виде платы уже есть GLB. Добавить параметрическую коробку-корпус вокруг платы (стенки,
   высота, монтажные стойки, отверстия под разъёмы) + экспорт в **STL** (для печати) и по возможности
   STEP. Это и есть «платы с корпусами» — закрывает виток «схема → плата → 3D-корпус». Изолировано в 3D.

## 🥈 Сильный вау, но крупнее/рискованнее — если останется время

4. **GNN — нейросеть предсказывает напряжения** — `L`, риск средний, **вау максимальный**
   Skeleton (`ml/gnn_simulator.py`) + команды train/eval есть. Дообучить на наборе схем, замерить
   «GNN vs MNA» (точность/скорость), показать график. Самая «диссертабельная» фича, но требует
   **отдельной фокус-сессии** (данные + обучение + бенч). Брать, если топ-3 закрыты заранее.

5. **Async AI + живой SSE-стриминг ответа** — `M`, риск средний (трогает AI-путь)
   `httpx.AsyncClient` + токен-стриминг ответа ассистента (вместо имитации typewriter). Питч
   «асинхронная AI-подсистема». Вау есть, но затрагивает рабочий чат → тестировать аккуратно.

## 🥉 Полировка-вау (мелочи с хорошим визуальным эффектом)

   U2Net убирает фон/тени с фото каталога → аккуратные карточки. Офлайн-обработка, runtime не трогает.
   Заметно улучшает скриншоты каталога для презентации/диплома.
7. **KaTeX — рендер формул** в ассистенте/симуляции — `S`, риск низкий
   Формулы (делитель, fc, P, MNA) красиво рендерятся вместо текста. Перекликается с формулами диплома.
8. **Datasheet Intelligence (PyMuPDF)** — `M-L`, риск низкий
   Из PDF-даташита тянуть pinout / absolute max / thermal. Вау, но зависит от наличия PDF-данных.

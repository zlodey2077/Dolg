# TODO: LECAD / Lithium ECAD как источник идей для CAD/SIM DOLG

Дата записи: 2026-05-31  
Ссылка для исследования: https://www.lecad.ru/sync-in-lithium-ecad/

## Идея

Нужно отдельно прошерстить сайт LECAD и изучить бесплатную версию программы Lithium ECAD как сильного конкурента в области разработки схем. Цель не в копировании интерфейса, а в понимании инженерной связки между CAD и симулятором: как схема, данные компонентов, связи, проверки, импорт/экспорт и расчетный контур живут в одной среде.

## Ограничение по безопасности и лицензии

Под “реверс-инжинирингом” фиксируем безопасный и законный формат исследования:

- изучить сайт, публичную документацию, демо, справку и обучающие материалы;
- установить бесплатную версию в отдельной sandbox/VM;
- анализировать поведение UI, форматы сохранения, экспорт/импорт, лог-файлы, открытые конфиги и сетевые запросы только в рамках лицензии;
- не обходить защиту, не патчить исполняемые файлы, не извлекать закрытые алгоритмы из бинарника;
- если лицензия запрещает анализ форматов или автоматизацию, использовать только black-box наблюдения и публичную документацию.

## Что нужно выяснить

1. Какие форматы поддерживаются:
   - проекты;
   - схемы;
   - библиотеки компонентов;
   - netlist;
   - BOM;
   - отчеты проверок;
   - экспорт изображений/PDF/таблиц.

2. Как устроена связка CAD -> SIM:
   - есть ли единая модель схемы;
   - как задаются компоненты, pins, nets, labels, GND;
   - как пользователь запускает расчет/симуляцию;
   - есть ли probes, измерения, графики, expected vs measured;
   - как программа связывает ошибку схемы с местом на полотне.

3. Как реализованы проверки:
   - ERC/DRC;
   - floating nodes;
   - отсутствие GND/источника;
   - ошибки соединений;
   - некорректные номиналы;
   - связь с корпусами/footprints/BOM.

4. Что можно перенести в DOLG как идею:
   - режим синхронизации CAD/SIM;
   - import preview;
   - подсветка узлов и ошибок;
   - проектный сеанс;
   - трасса “схема -> проверка -> измерение -> отчет”;
   - связка “компонент схемы -> товар каталога -> BOM”.

5. Что можно использовать для AI и обучения:
   - типовые ошибки пользователя;
   - сценарии диагностики;
   - учебные задания на чтение схемы;
   - примеры форматов, если они открыты и разрешены лицензией;
   - сравнительная таблица возможностей для диплома.

## Возможные фичи DOLG после исследования

- “Sync mode”: живое соответствие между CAD canvas, netlist, simulation graph и BOM.
- “Explain net”: клик по узлу показывает net, связанные компоненты, расчетные точки и последние измерения.
- “Review overlay”: ошибки Engineering Review подсвечиваются прямо на схеме.
- “Export compatibility pack”: проект DOLG выгружается как набор `scheme_data + netlist + BOM + review + measurements`.
- “Import adapter V2”: расширить текущий LTspice/SPICE/KiCad subset по мотивам обнаруженных открытых форматов.

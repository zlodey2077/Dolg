## Tier 1 — глубина движка (ассистент/симулятор, клиент, низкий риск, готовый ресёрч)
4. **Нелинейный MNA — Newton для диода/LED** (§W): companion-модель `Gd+Ieq`, итерации → корректный ток LED (сейчас DC линейный). **Самый ценный для «настоящести» расчёта.**
5. **Транзиент (TRAN) в JS-MNA** (§AC): companion-модели C/L + шаг по времени (Backward Euler) → переходные процессы на клиенте без ngspice.
6. **derating-factor + доменные пороги** (§AK, 50/75/80%) + **движок линейного стабилизатора** (§AL: dropout, P=(Vin−Vout)·I, подбор 78xx) — расширяют ассистент (thermal/«собери стабилизатор»).
7. **Тепловой расчёт T_j** (§Y): `T_j=Ta+P·R_θ` + флаг превышения (тем же MNA как резисторная сеть).
8. **Logic-движок** (§AN): AND/OR/NOT, таблицы истинности, СДНФ — отдельная цифровая ветка (нужны логические компоненты в редакторе).

## Tier 2 — вау-пайплайн схема→PCB→3D
9. **Один клик «схема→плата→3D»** — бесшовный переход (сейчас разные страницы).
10. **Медные дорожки с толщиной + soldermask поверх** в 3D (§AF) — «как настоящая» плата.
11. **Rip-up & reroute** в автотрассировщике (§AD) — меньше неразведённых нетов.
12. **DRC PCB-слоя** (§N/§AB): clearance ≥3×диэлектрик, ширина по току (IPC-2221), «сигнал над разрывом земли», близость decoupling-капа.

## Tier 3 — клиентский движок на максимум (§M, перф)
